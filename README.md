 # UTS-WEB-DHEA

Interactive Personal Portfolio untuk UTS Pemrograman Web (Program Studi Sistem Informasi).

## Live Website
https://dheacahyaningputri.github.io/UTS-WEB-DHEA-CAHYANING-PUTRI/

## Fitur
- HTML5 semantik (header, nav, main, section, article, aside, footer) dengan meta tag lengkap
- Bootstrap 5 + custom CSS, tema pastel taupe, responsif di desktop, tablet, dan mobile
- Dark mode toggle (tersimpan di localStorage)
- Efek mengetik, animasi reveal saat scroll, progress bar skill, dan counter angka
- Filter kategori dan pencarian proyek
- Kalkulator estimasi biaya proyek web
- Validasi form kontak
